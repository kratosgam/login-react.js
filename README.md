# Logim 🔐

Uma aplicação web moderna desenvolvida para praticar conceitos fundamentais de Front-end, como componentes funcionais, gerenciamento de estados e renderização eficiente. O projeto utiliza o ecossistema React 19 e é otimizado com o Vite para um desenvolvimento extremamente rápido.

# 📝 Sobre o Projeto

O Logim (uma variação estilizada de "Login") é um projeto focado na construção de interfaces de autenticação. Ele serve como base para estudos de fluxos de usuário, validação de formulários e integração com APIs modernas.

## Principais Objetivos:

Componentização: Criação de interfaces reutilizáveis e modulares.

Performance: Utilização do Vite para carregamento rápido e HMR (Hot Module Replacement).

Boas Práticas: Código estruturado com ESLint para garantir consistência e evitar erros comuns.

# 🛠️ Tecnologias Utilizadas

React 19: A versão mais recente da biblioteca para construção de interfaces de usuário.

Vite 8: Ferramenta de build de última geração para um ambiente de desenvolvimento ágil.

JavaScript (ES6+): Lógica moderna para manipulação de dados e estados.

ESLint: Ferramenta de linting para garantir a qualidade do código.

HTML5/CSS3: Estrutura e estilização da aplicação.

# 📂 Estrutura Principal
index.html: Ponto de entrada do navegador com o elemento raiz para o React.

src/main.jsx: Arquivo principal onde a aplicação React é inicializada e renderizada.

package.json: Gerenciamento de dependências e scripts de execução do projeto.

.eslintrc.js: Configurações de padronização de código.

# 🚀 Instruções de Instalação
Para rodar este projeto localmente, siga os passos abaixo:

## 1. Clone este repositório:

``Bash``

git clone https://github.com/kayomatheus/logim.git

## 2. Acesse a pasta do projeto:

``Bash``

cd logim

## 3.Instale as dependências:

``Bash``

npm install

## 4.Inicie o servidor de desenvolvimento:

``Bash``

npm run dev

## 5.Acesse no seu navegador:

O terminal informará um endereço como http://localhost:5173.
